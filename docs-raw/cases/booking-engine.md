# Кейс: Модуль онлайн-бронирования

## Контекст

Большинство отелей отдают значительную часть бронирований агрегаторам: OTA берут 15–25%
комиссии с каждого заезда. При этом собственный сайт есть практически у каждого отеля,
но конвертирует плохо — нет удобного движка бронирования или он уступает по UX
агрегаторскому. Гость заходит на сайт, не находит простого способа забронировать
и уходит обратно на OTA.

## Задача

Разработать собственный модуль онлайн-бронирования, который обеспечит конверсию
сопоставимую с агрегаторами, при этом позволяя отелю принимать прямые бронирования
без комиссии.

## Что было сделано

### 1. Движок бронирования на сайте

Модуль встраивается на сайт отеля и предоставляет гостю:
- выбор дат заезда и выезда,
- выбор категории номера с фотографиями и описанием,
- выбор тарифа (завтрак включён / без питания / «всё включено»),
- указание состава гостей (взрослые + дети с возрастами),
- просмотр итоговой стоимости с разбивкой.

Интерфейс адаптирован для мобильных устройств.

### 2. Прямые преимущества для гостя

Чтобы мотивировать гостей бронировать напрямую, на сайте транслируются:
- «Лучшая цена гарантирована»,
- бонусные баллы за прямое бронирование,
- ранний заезд / поздний выезд для прямых гостей,
- эксклюзивные пакеты, недоступные на OTA.

### 3. Подключение СБП

Интеграция с Системой быстрых платежей снижает эквайринговую комиссию с 1,5–2,5%
до 0,4–0,7%. На объёмах среднего отеля экономия исчисляется сотнями тысяч рублей в год.

### 4. Интеграция с PMS

Каждое бронирование через модуль автоматически создаётся в PMS:
- данные гостя,
- даты и категория номера,
- тариф и сумма,
- источник бронирования (для аналитики).

Никакого ручного переноса, никаких дублей.

### 5. Аналитика бронирований

Административная панель модуля показывает:
- число зарегистрированных пользователей и входов,
- конверсию из визита на сайт в бронирование,
- выручку по периодам,
- соотношение прямых и OTA-бронирований в динамике.

## Результат

- Доля прямых бронирований в общей выручке растёт после запуска модуля.
- Экономия на комиссии OTA частично направляется в программу лояльности —
  создаётся позитивный цикл.
- Отель получает данные о гостях сразу при бронировании, а не после заезда.

## Что важно учесть

- Модуль без трафика не работает. SEO-продвижение сайта и direct-маркетинг —
  обязательное условие для роста прямых продаж.
- Price parity (ценовой паритет) с OTA: если на сайте дороже, чем на Ostrovok —
  гость уйдёт. Нужна либо лучшая цена, либо очевидная дополнительная ценность.
- Скорость загрузки критична: форма бронирования должна открываться за 1–2 секунды.
