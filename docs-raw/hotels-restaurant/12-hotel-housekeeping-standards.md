# Housekeeping: организация смен, нормы времени на номер

> **Серия:** Отели — операции  
> **Уровень:** Операционный  
> **Аудитория:** Менеджеры хаускипинга, супервайзеры, управляющие

---

## Почему хаускипинг — это не просто уборка

Грязный номер — самая частая причина негативных отзывов на Booking.com и TripAdvisor. При этом хаускипинг — один из крупнейших переменных расходов отеля. Управление им — это баланс между скоростью, качеством и стоимостью.

**Финансовая логика:** Повышение эффективности хаускипинга напрямую увеличивает GOP (Gross Operating Profit) — быстрый оборот номеров позволяет принимать короткие бронирования, а снижение расхода химии и времени снижает себестоимость.

---

## Структура отдела хаускипинга

| Позиция | Ответственность |
|---|---|
| Менеджер хаускипинга | Бюджет, рекрутинг, стандарты, KPI всего отдела |
| Ассистент менеджера | Оперативное управление в отсутствие менеджера |
| Супервайзер этажа | Контроль команды на своих этажах, инспекция номеров |
| Супервайзер публичных зон | Лобби, рестораны, переходы, бассейн |
| Горничная / Room Attendant | Уборка номеров |
| Лаундри-супервайзер | Управление запасами белья, контроль качества |

## Нормы времени на номер: реальные цифры

Отрасль часто называет завышенные нормы (20–25 номеров на смену), которые достигаются за счёт качества. Более честные ориентиры:

| Тип уборки | Норма времени | Номеров за 8-часовую смену |
|---|---|---|
| Stayover (гость остаётся) | 15–20 минут | 14–16 номеров |
| Checkout (новый гость) | 30–45 минут | 10–13 номеров |
| Оптимальный стандарт | 35–40 минут (checkout) | 12–13 номеров |
| Глубокая уборка | 60–90 минут | 5–6 номеров |

> **Важный принцип:** Норма 20–25 номеров за смену — путь к выгоранию персонала и жалобам гостей. Лучше 12 номеров, убранных хорошо, чем 20, убранных плохо. Сэкономите на жалобах, которые стоят репутации.

**Система кредитов (Room Credits):**
- Стандартный номер = 1 кредит
- Сьют / большой номер = 1.5–2 кредита
- Апартаменты с кухней = +0.5 кредита
- Номер на высоком этаже (дополнительное время на переезд) = учитывается

## Организация смены: от планёрки до завершения

### 08:00 — Утренняя планёрка (10–15 минут)

- Загрузка дня: сколько checkout, сколько stayover, особые запросы
- Распределение номеров по горничным с учётом кредитов
- Сообщение о VIP-гостях и особых пожеланиях
- Напоминание о стандарте дня (одна деталь, требующая внимания)

### 08:15 — Начало работы

- Приоритет: checkout-номера (освободить для нового заезда)
- Следующий приоритет: stayover по отметке DND (Do Not Disturb)
- Параллельно: запросы от гостей в реальном времени

### 12:00 — Промежуточный контроль

Супервайзер проверяет выполненное и корректирует план при необходимости.

### 14:00–15:00 — Основная смена завершена

Супервайзер обходит проверенные номера. Менеджер оценивает KPI дня.

## Чек-лист стандартной уборки номера (Checkout)

**Вход и подготовка:**
- [ ] Открыть окно для проветривания
- [ ] Вынести весь мусор, заменить пакеты
- [ ] Собрать использованное бельё и полотенца

**Спальная зона:**
- [ ] Поменять постельное бельё (матрас, подушка, пододеяльник)
- [ ] Вытереть пыль: тумбочки, лампы, TV, рамки
- [ ] Очистить и проверить холодильник / мини-бар
- [ ] Проверить работу всех розеток, ламп, TV, кондиционера

**Ванная комната:**
- [ ] Вымыть унитаз (включая под крышкой и основание)
- [ ] Вымыть раковину и кран
- [ ] Почистить душевую кабину / ванну от известковых отложений
- [ ] Зеркало: без следов и разводов
- [ ] Заменить все туалетные принадлежности новыми
- [ ] Свежие полотенца в установленном порядке

**Финальные детали:**
- [ ] Пропылесосить весь ковёр / влажная уборка пола
- [ ] Проверить балкон / лоджию
- [ ] Финальный осмотр с точки зрения гостя (войти и посмотреть «первым взглядом»)
- [ ] Приветственный знак / декоративный элемент (если стандарт отеля)

## Инспекция номеров: роль супервайзера

Каждый номер перед сдачей должен быть проверен супервайзером. Это не бюрократия — это защита от жалоб.

**Что проверяет супервайзер:**
1. Бельё — нет пятен, правильно заправлено
2. Ванная — нет волос, известковых разводов, все принадлежности
3. Запах — нет посторонних запахов
4. Техника — всё работает
5. «Гостевой взгляд» — зайдите и оцените, как гость

**Система оценки:** Каждая горничная получает ежемесячный score на основе инспекционных оценок. Топ-3 по итогам месяца — признание (небольшая премия, публичная благодарность на планёрке).

## Управление расходными материалами

Хаускипинг — крупная статья переменных расходов. Контроль помогает снизить затраты без ущерба качеству.

**Основные метрики:**
- Расход химии на номер (кг / номер / месяц)
- Списание белья (% от оборота)
- Количество запасных комплектов белья (норма: 3 комплекта на номер)

**Принцип порционирования:** Химия должна выдаваться в мерных ёмкостях или картриджах. Открытые канистры «на глаз» ведут к перерасходу в 2–3 раза.

---

## Управление публичными зонами

Лобби, коридоры, рестораны, бассейн, спортзал — всё это тоже зоны хаускипинга.

**Расписание публичных зон:**
- Лобби: ротация каждые 30–45 минут
- Лифты: каждый час
- Конференц-залы: после каждого мероприятия
- Бассейн: утром до открытия + каждые 2 часа
- Туалеты общего пользования: каждые 30–60 минут
