## Инструкция

1. Скачай файл → положи в нужную подпапку (`pos/`, `pms/`, `delivery/`, `reservation/`)
2. Сообщи в чате: `добавил <имя файла> — обработай`
3. После обработки файл перемещается в раздел «Обработаны»
