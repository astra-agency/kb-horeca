# Цифровой ID в МАКС для заселения в отели

> **Ключевой источник**: «Половина российских отелей уже может заселять гостей через цифровой ID в мессенджере МАКС», — Рустам Хайбуллов, вице-президент VK по стратегическим проектам (форум «Путешествуй!», июнь 2026)

## Основные факты

- **Постановление № 1912** — с 1 марта 2026 года введена возможность заселения в гостиницы через мессенджер MAX
- **VK анонсировал пилот** в ноябре 2025 (Интерфакс)
- **Пилот стартовал в апреле 2026** в 6 отелях: Four Seasons Hotel Moscow, Mantera Supreme Seaside, Сочи Парк Отель, отели сети Cosmos
- **Регионы пилота**: Москва, Санкт-Петербург, Сочи, Татарстан
- **По состоянию на июнь 2026**: ~50% средств размещения РФ получили техническую возможность заселять по цифровому ID
- **План до конца года**: подключить крупные отели и сети «по умолчанию»
- **Механика**: гость открывает MAX → Цифровой ID → Паспорт → QR-код на стойке регистрации (вместо бумажного паспорта и анкеты)
