## Типичный стек ресторана в РФ

```
POS-система (iiko / r_keeper / Poster)
  ├── Кухонный экран (KDS)
  ├── Склад и фудкост
  ├── Онлайн-касса (54-ФЗ)
  └── Интеграции:
        ├── Доставка (Яндекс.Еда, Delivery Club)
        ├── Программа лояльности
        └── Резервация (Restoplace, ТоМесто)
```

## Выбор POS-системы

| Размер / формат | Рекомендация |
|---|---|
| Кофейня, небольшое кафе | Poster, r_keeper Cloud |
| Ресторан с кухней | iiko, r_keeper |
| Сеть / франшиза | iiko, r_keeper LifeTime |
| Dark kitchen | iiko Delivery, r_keeper Delivery |

| Характеристика | Значение |

Шаблон для кейтеринга и банкетного сервиса.

| Характеристика | Значение |
|---|---|

**Полезные плагины для сайта ресторана:**
