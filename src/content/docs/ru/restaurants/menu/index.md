## Ключевые формулы

```
Food Cost % = (Себестоимость / Цена продажи) × 100

Contribution Margin = Цена продажи − Себестоимость

Prime Cost % = (Food Cost + Labor Cost) / Выручка × 100
```

**Целевые показатели:** Food cost 28–35%, Prime cost ≤65% для casual dining.
