## Зачем нужен сайт с прямым бронированием

OTA (Ostrovok, Яндекс.Путешествия, Booking) берут комиссию 15–25%. Прямое бронирование через сайт — нулевая комиссия. Окупаемость сайта с модулем бронирования — от 1–3 месяцев.

## Платформы для сайта

### WordPress

Наиболее гибкий вариант. Полный контроль над дизайном, SEO, функциональностью.

**Тема Blocksy** — быстрая WordPress-тема с готовыми стартовыми шаблонами:

#### Стартовый сайт Travel

Готовый шаблон для отеля, гостевого дома, туристического бизнеса.

**Рекомендуемые плагины для бронирования:**
- **MotoPress Hotel Booking** — управление номерами, доп. услугами, галереями, расчёт стоимости
- **WP Hotel Booking** — бронирование номеров с ценовыми правилами
- **Appointment Booking (MotoPress)** — для объектов с почасовой записью (спа, экскурсии)

**Процесс создания сайта отеля на WordPress + Blocksy:**
1. Установить WordPress + тему Blocksy
2. Импортировать стартовый сайт Travel (1 клик)
3. Установить MotoPress Hotel Booking
4. Настроить номера, тарифы, календарь доступности
5. Подключить платёжный шлюз
6. Интегрировать с Channel Manager через API

### Tilda
- Быстрый старт, визуальный редактор
- Подходит для небольших объектов без сложного бронирования
- Ограниченная кастомизация
- Модуль бронирования — через сторонний виджет (TravelLine, Bnovo)

| Сервис | Особенности |

| **TravelLine** | Лидер рынка РФ, встроен в PMS TravelLine, полная синхронизация |
| **Bnovo** | Хорошая интеграция с собственной PMS Bnovo |
| **Бронируй.Онлайн** | Простая настройка, доступная цена, независимый виджет |
| **Saby Hotel виджет** | Встроен в экосистему Saby, настройка 5 минут |

## Интеграция с Channel Manager

Модуль бронирования должен быть связан с Channel Manager — чтобы доступность номеров обновлялась в реальном времени и не было овербукинга.

```
Сайт (виджет) → Channel Manager → PMS → OTA
```

При прямом брони через сайт — Channel Manager автоматически закрывает даты на всех OTA.

## Что должно быть на сайте отеля

- Описание и фотографии номеров
- Виджет бронирования с актуальными ценами
- Информация об услугах (ресторан, спа, парковка)
- Расположение с картой
- Контакты и форма обратной связи
- Отзывы (виджет TripAdvisor, Яндекс.Карты)
