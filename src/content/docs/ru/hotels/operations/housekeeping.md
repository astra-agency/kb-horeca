## Хаускипинг — невидимая основа репутации

Гость замечает хаускипинг только когда что-то не так. Пятно на полотенце, волос в ванной, не убранный мусор — всё это мгновенно попадает в отзыв. Идеальная уборка воспринимается как само собой разумеющееся.

Именно поэтому хаускипинг — самый важный и самый недооценённый отдел.

---

## Нормативы производительности

| Тип уборки | Норма (одна горничная) | Примечание |
|---|---|---|
| Уборка после выезда (полная) | 30–45 мин / номер | Зависит от категории и площади |
| Текущая уборка (гость проживает) | 20–30 мин / номер | При отказе от уборки — пропустить |
| Номер без уборки (DND > 3 дней) | Обязательная проверка | Безопасность |
| Нагрузка на горничную | 10–14 номеров / смена | Стандарт на 8-часовую смену |

Превышение нормы > 15 номеров на человека = снижение качества и риск травм.

## Типы уборок и когда проводятся

### Уборка после выезда (Checkout Cleaning)
Самая полная. Проводится после освобождения номера.

**Обязательно:**
- Полная замена постельного белья и полотенец
- Уборка всех поверхностей (включая под кроватью)
- Дезинфекция ванной комнаты (унитаз, раковина, душевая/ванна)
- Проверка работоспособности техники (ТВ, свет, кондиционер)
- Пополнение туалетных принадлежностей до стандарта
- Проверка мини-бара
- Уборка следов предыдущего гостя (личные вещи, мусор, следы на зеркалах)

### Текущая уборка (Stay-over Cleaning)
Гость продолжает проживать. Проводится по запросу или ежедневно.

**Минимум:**
- Замена полотенец по знаку гостя (на полу = замена, на крючке = оставить)
- Уборка мусора
- Застилание кровати
- Пополнение расходников

### Вечерняя подготовка (Turndown Service)
В отелях уровня 4-5*. Проводится вечером: подготовка кровати ко сну, занавески, ночник, шоколад на подушке.

## Алгоритм уборки номера

**Правило сверху вниз:** Начинать с высоких поверхностей, заканчивать полом.

1. Войти, открыть окно, проветрить
2. Убрать мусор и загрязнённое бельё
3. Ванная комната: дезинфекция поверхностей → унитаз → раковина → зеркало → пол
4. Жилая зона: протереть поверхности → пополнить расходники → кровать → пыль на мебели
5. Пол: пылесос → влажная уборка (при необходимости)
6. Финальный осмотр по чеклисту
7. Закрыть окно, включить стандартное освещение

---

## Чеклист приёмки номера

- [ ] Кровать: бельё белое, без пятен, углы заправлены
- [ ] Ванная: унитаз, раковина, ванна/душ без следов и запаха
- [ ] Полотенца: белые, без пятен, сложены по стандарту
- [ ] Расходники пополнены (гель, шампунь, мыло, туалетная бумага)
- [ ] Зеркала: без разводов
- [ ] Мусор: все корзины пусты
- [ ] Пол: чистый
- [ ] Техника: работает (ТВ, свет, кондиционер, розетки)
- [ ] Личных вещей предыдущего гостя нет
- [ ] Запах: нейтральный

## Организация смены

**Утренняя планёрка (10–15 мин):**
- Распределение номеров (приоритет — выезды, потом занятые, потом ожидаемые заезды)
- Сообщение о VIP-гостях и особых пожеланиях
- Статус проблемных номеров (техника, повреждения)

**Приоритет уборки:**
1. Номера с запросом на раннее заселение
2. Номера со статусом выезда
3. Текущая уборка по запросу
4. Плановая ежедневная уборка

**Связь с ресепшеном:** Горничная сообщает о статусе номера сразу после уборки → ресепшен может заселить раньше.

---

## Контроль качества

**Инспекция:** Старший горничной проверяет 20–30% убранных номеров.

**Система оценки:** По чеклисту с баллами. Итоговая оценка = часть KPI горничной.

**Обратная связь от гостей:** Отзывы на Booking и Яндексе с упоминанием чистоты — индикатор работы хаускипинга.

## Типичные ошибки и их причины

| Ошибка | Причина | Решение |
|---|---|---|
| Следы на зеркале | Нет чеклиста / спешка | Включить в стандарт |
| Не убрана зона под кроватью | Перегрузка / нет контроля | Уменьшить нагрузку |
| Пятно на бельё | Недостаточная стирка | Контроль качества прачечной |
| Не пополнены расходники | Забыли / нет запасов на тележке | Стандарт комплектации тележки |
| Запах дыма / посторонний | Не проветрили / курение в номере | Протокол обнаружения + штраф гостю |
