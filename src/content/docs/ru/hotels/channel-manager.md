## Что такое Channel Manager

**Channel Manager** — система, которая синхронизирует наличие номеров и цены между PMS отеля и всеми подключёнными OTA в режиме реального времени.

**Главная задача:** исключить овербукинг при продажах через несколько каналов одновременно.

## Как работает

```
PMS (обновление доступности)
  → Channel Manager (синхронизация за 3–7 сек)
    → Ostrovok
    → Яндекс.Путешествия
    → Booking.com
    → Bronevik
    → Авито Недвижимость
    → ... (до 130+ площадок)
```

При поступлении брони с любого канала — доступность автоматически снижается на всех остальных.
