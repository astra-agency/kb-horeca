## О продукте

**TravelLine** — лидер российского рынка гостиничного ПО. Полный стек: PMS + Channel Manager + модуль онлайн-бронирования + репутационный менеджмент + сайт. Более **6 200+ объектов** используют систему.

## Модули

### TL: WebPMS — система управления отелем
Облачная АСУ, работает через браузер без установки.

- Шахматка — визуализация номеров и бронирований по датам
- Создание и редактирование броней, check-in / check-out
- Управление статусом номеров и уборкой
- Почасовые брони
- Ссылки на оплату для гостей
- Миграционный учёт (регистрация в МВД)
- Финансовый учёт и отчётность

### TL: Channel Manager
130+ каналов — OTA, туроператоры, GDS. Синхронизация за 3–7 секунд.

**Тариф:** 3 000 ₽/мес (скидки: 5% квартал / 10% полгода / 15% год)

### TL: Booking Engine
Модуль прямого бронирования на сайт — показывает доступные номера, тарифы, доп. услуги, принимает оплату.

### TL: Reputation
Мониторинг отзывов с 27+ площадок, ИИ-анализ по 35 категориям, автогенерация ответов.

**Тариф:** 1 950 ₽/мес + 1 950 ₽/мес за ИИ-анализ

### TL: Rate Shopper
Анализ цен конкурентов по категориям номеров.

### TL: Price Optimizer
Автоматическое динамическое ценообразование на основе загрузки.

### TL: GMS
Сегментация гостей и рассылки.
