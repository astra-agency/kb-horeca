## Рестораны: POS ↔ другие системы

### iiko — интеграции

| Система | Тип интеграции | Что даёт |
|---------|---------------|---------|
| Яндекс Еда | Прямая (API) | Заказы из агрегатора автоматически попадают в кассу |
| Delivery Club / SberFood | Прямая (API) | То же |
| Plazius | Двусторонняя | Синхронизация гостей, бонусов, истории заказов |
| Mindbox | Двусторонняя | CRM-данные, сегментация, автоматические рассылки |
| TravelLine | Двусторонняя | Ресторан внутри отеля: заказы на номер, единый счёт |
| Logus HMS | Двусторонняя | То же |
| 1С Бухгалтерия | Выгрузка | Финансовые данные, товарный учёт |
| Bitrix24 / amoCRM | API | Гости, маркетинг |
| Атол, Эвотор, ШТРИХ-М | Прямая | Онлайн-касса (54-ФЗ) |
| ЕГАИС (Честный знак) | Прямая | Учёт алкоголя |

## Связки систем

### Ресторан с программой лояльности
```
iiko → iikoCard5 (базовая лояльность)
iiko → Plazius (мобильная лояльность + SberFood)
iiko → Mindbox (enterprise CRM + омниканал)
```

### Ресторан + доставка
```
iiko → Яндекс Еда (прямая) + Delivery Club (прямая)
r_keeper → r_keeper Delivery → агрегаторы
Poster → маркетплейс приложений → агрегаторы
```

### Отель с рестораном
```
TravelLine PMS → iiko (заказы на номер)
TravelLine PMS → r_keeper (заказы на номер)
```

### Отель + OTA
```
TravelLine PMS → TravelLine Channel Manager → 130+ OTA
Bnovo PMS → Bnovo Channel Manager → основные OTA
MaxiBooking PMS → встроенный CM → OTA
```
