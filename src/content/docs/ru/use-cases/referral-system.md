## Контекст

Сарафанное радио всегда работало в гостиничном бизнесе. Реферальная система — это
его оцифрованная и измеримая версия: гость делится персональной ссылкой, приводит
нового гостя и получает бонус. Отель приобретает клиента с высоким уровнем доверия
и по цене в разы ниже, чем через OTA.

## Задача

Построить реферальную механику, встроенную в программу лояльности: с персональными ссылками,
автоматическим начислением бонусов и статистикой для гостя.

## Что было сделано

### 1. Персональные реферальные ссылки

Каждый участник программы лояльности получает уникальную реферальную ссылку в личном кабинете.
Ссылку можно скопировать или отправить напрямую через Telegram, WhatsApp, Viber.

Когда новый гость бронирует по этой ссылке — система фиксирует источник.

### 2. Двусторонняя мотивация

Программа выгодна обеим сторонам:

| Кто | Что получает |
|---|---|
| Реферер (тот, кто пригласил) | % от стоимости первого бронирования нового гостя — на бонусный счёт |
| Новый гость | % на бонусный счёт за первое бронирование по реферальной ссылке |

Оба начисления происходят автоматически после состоявшегося заезда.

### 3. Статистика для гостя

В личном кабинете гость видит:
- сколько друзей зарегистрировались по его ссылке,
- сколько бонусов заработано и начислено,
- сколько ожидает начисления (после заезда приглашённых гостей).

Прозрачность мотивирует делиться ссылкой активнее.

### 4. Работа с блогерами

Реферальный механизм особенно эффективен при сотрудничестве с инфлюенсерами:
блогер получает персональную ссылку и делится ею с аудиторией. Отель видит
точное число бронирований по каждому блогеру и может оценить реальную отдачу
от сотрудничества — без субъективных оценок охвата и «узнаваемости».

### 5. Аналитика реферальной программы

Метрики для управления программой:
- число активных рефереров,
- конверсия из перехода по ссылке в бронирование,
- средний чек привлечённых гостей,
- стоимость привлечения через реферальный канал vs OTA.

## Результат

- Реферальный канал обеспечивает поток новых гостей с минимальной стоимостью привлечения.
- Гости-рефереры демонстрируют более высокую лояльность: они вовлечены в жизнь отеля.
- При работе с блогерами отель получает измеримый результат вместо имиджевых метрик.

## Что важно учесть

- Программа работает только если у отеля уже есть база лояльных гостей — некому реферировать при нулевой базе.
- Реферальный бонус должен быть достаточно привлекательным, чтобы мотивировать делиться, но не настолько щедрым, чтобы создавать злоупотребления.
- Необходима защита от накруток: одно устройство — одна регистрация, бонус начисляется только после состоявшегося заезда.
