## Что такое 54-ФЗ

Федеральный закон №54-ФЗ «О применении контрольно-кассовой техники» обязывает все организации и ИП, принимающие оплату наличными и картами, использовать онлайн-кассы с передачей данных в ФНС через оператора фискальных данных (ОФД).

Закон распространяется на рестораны, кафе, бары, отели — любой бизнес, принимающий оплату от физических лиц.

## Как работает схема

```
Гость платит → Касса фиксирует → ФН (фискальный накопитель) → ОФД → ФНС
```

1. **Кассовый аппарат** — должен быть в реестре ФНС
2. **Фискальный накопитель (ФН)** — устройство внутри кассы, хранит чеки; срок действия 15 или 36 месяцев
3. **ОФД** — посредник между кассой и ФНС, передаёт данные онлайн
4. **ЛК ФНС** — налоговая видит все чеки в реальном времени

## Что нужно сделать

1. Купить кассу из реестра ФНС (или арендовать)
2. Заключить договор с ОФД
3. Зарегистрировать кассу в личном кабинете ФНС
4. Настроить передачу данных в вашу POS-систему

## Особенности для ресторанов

- **Расчёт при закрытии счёта** — фискальный чек пробивается в момент оплаты, не при приёме заказа
- **Самообслуживание (киоски)** — каждый киоск = отдельная касса
- **Доставка** — при оплате курьеру нужна мобильная касса или эквайринг
- **Банкеты с предоплатой** — аванс фискализируется как предоплата, остаток — при закрытии

## Особенности для отелей

- **Проживание** — оплата при заезде или выезде фискализируется кассой
- **Ресторан внутри отеля** — отдельная касса или единая с разделением по подразделениям
- **Доп. услуги (спа, парковка)** — тоже требуют кассы

## Штрафы за нарушения
