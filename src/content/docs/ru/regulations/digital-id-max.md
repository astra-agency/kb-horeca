## Нормативная база

**Постановление Правительства РФ № 1912** — с 1 марта 2026 года введена возможность заселения в гостиницы с использованием цифрового ID в национальном мессенджере МАКС (MAX) от VK. Цифровой ID приравнивается к бумажному паспорту при регистрации гостя.

Постановление дополняет существующие нормы регистрации гостей (см. [Регистрация гостей в МВД](./fms-hotels.md)).

## Что такое цифровой ID в МАКС

Цифровой ID — это функция мессенджера МАКС, которая подтягивает данные паспорта с портала Госуслуг и формирует QR-код. Гость показывает QR-код на стойке регистрации — сотрудник отеля сканирует его и получает паспортные данные без ручного ввода и бумажной анкеты.

### Ключевые возможности

- **Отображение паспорта** — электронная версия документа из Госуслуг
- **QR-код для сканирования** — на стойке регистрации
- **Подтверждение возраста** — для покупок с возрастным ограничением
- **Авторизация** — в отдельных сервисах и офлайн-кейсах

## Хронология внедрения

| Дата | Событие |
|------|---------|
| Ноябрь 2025 | VK анонсировал пилотный проект (Интерфакс) |
| 1 марта 2026 | Вступило в силу Постановление № 1912 |
| Апрель 2026 | Пилотный запуск в 6 отелях |
| Июнь 2026 | ~50% средств размещения РФ получили техническую возможность |

## География пилотного проекта

Пилот стартовал в четырёх регионах:

- **Москва** — Four Seasons Hotel Moscow, отели сети Cosmos
- **Санкт-Петербург**
- **Сочи** — Mantera Supreme Seaside, «Сочи Парк Отель»
- **Татарстан**

## Как это работает

### Для гостя

1. Открыть мессенджер **МАКС**
2. Перейти в раздел **«Цифровой ID»** в профиле
3. Открыть вкладку **«Паспорт»**
4. Показать **QR-код** сотруднику отеля на стойке регистрации

Гость **не заполняет бумажную анкету** и не предъявляет бумажный паспорт. Все данные автоматически подтягиваются из Госуслуг.

### Для отеля

1. Сотрудник сканирует QR-код гостя
2. Система получает паспортные данные
3. Данные автоматически заполняются в форму регистрации
4. PMS формирует уведомление в МВД (через интеграцию, см. [Регистрация гостей в МВД](./fms-hotels.md))

## Какие отели подключены

По заявлению вице-президента VK по стратегическим проектам **Рустама Хайбуллова** (форум «Путешествуй!», июнь 2026):

> «Практически половина средств размещения РФ уже получили возможность заселять в гостиницы по цифровому ID в MAX»

До конца 2026 года планируется подключение крупных отелей и сетей «по умолчанию». Минцифры прогнозирует расширение до **нескольких тысяч гостиниц в течение года**.

### Подтверждённые участники пилота

- Four Seasons Hotel Moscow
- Mantera Supreme Seaside (Сочи)
- Сочи Парк Отель
- Отели сети Cosmos
- Отели в Татарстане (тестовый режим)

## Интеграция с PMS

На данный момент интеграция цифрового ID происходит на уровне системы заселения, подключённой к МАКС. Отелям, которые хотят подключиться, необходимо:

1. Убедиться, что PMS поддерживает интеграцию с цифровым ID МАКС
2. Подключиться к системе через партнёров VK или Минцифры
3. Обучить персонал работе с QR-сканированием

Точный перечень PMS с поддержкой уточняется — рекомендуется обратиться к поставщику PMS или следить за обновлениями на сайте Минцифры.

## Преимущества для отеля

- **Ускорение check-in** — нет ручного ввода паспортных данных и заполнения анкет
- **Меньше ошибок** — данные подтягиваются автоматически, исключаются опечатки
- **Соответствие 54-ФЗ и требованиям МВД** — цифровой след регистрации
- **Экономия бумаги** — отказ от бумажных анкет
