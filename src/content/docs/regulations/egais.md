## Что такое ЕГАИС

ЕГАИС (Единая государственная автоматизированная информационная система) — система Росалкогольрегулирования для учёта оборота алкоголя. Все организации, торгующие или использующие алкоголь в коммерческих целях, обязаны работать через ЕГАИС.

## Кому нужна ЕГАИС

- Рестораны, кафе, бары — подтверждение факта закупки алкоголя
- Продажа в розлив — подтверждение каждой бутылки
- Розничная продажа (бутылками) — полный учёт с поштучной маркировкой

**Исключение:** ИП на патенте в сельской местности — упрощённый режим.

## Что нужно для подключения

1. **Лицензия** на розничную продажу алкоголя (или лицензия на общепит)
2. **КЭП** (квалифицированная электронная подпись) для организации
3. **УТМ** (универсальный транспортный модуль) — ПО от Росалкогольрегулирования
4. **Сканер штрихкодов** — для считывания акцизных марок
5. **Интеграция с учётной системой** (iiko, 1С и др.)

## Что подтверждать через ЕГАИС

| Операция | Действие в ЕГАИС |
|----------|----------------|
| Получение товара от поставщика | Подтвердить накладную (ТТН) |
| Возврат поставщику | Создать акт возврата |
| Списание (бой, истёкший срок) | Акт списания |
| Продажа в розницу (бутылками) | Сканирование марки при продаже |
| Продажа в розлив (рестораны) | Списание из регистра — не поштучно |

## Регистры ЕГАИС

- **Регистр 1** — склад (бутылки с акцизными марками)
- **Регистр 2** — производство/торговый зал (открытая продукция, розлив)

Ресторан: большинство алкоголя хранится в Регистре 1, при открытии бутылки перемещается в Регистр 2.

## Интеграция с POS-системами

| POS | Интеграция с ЕГАИС |
|-----|-------------------|
| **iiko** | Встроенная интеграция — подтверждение ТТН, списание, маркировка |
| **r_keeper** | Встроенная через модуль StoreHouse |
| **Poster** | Через сторонние решения (ограниченно) |
| **1С:Ресторан** | Нативная интеграция |

## Важные сроки

- **Подтверждение ТТН** — не позднее рабочего дня, следующего за днём приёмки
- **Акты списания** — ежеквартально минимум, лучше ежемесячно
- **Инвентаризация** — фактические остатки должны совпадать с ЕГАИС
