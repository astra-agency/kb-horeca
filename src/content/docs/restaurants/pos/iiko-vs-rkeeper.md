## Краткий вывод

**iiko** — облачная экосистема «всё в одном». Единая база данных, современный интерфейс, быстрый онбординг персонала. Идеально для тех, кто хочет запустить всё из одной системы.

**r_keeper** — модульный конструктор с 30-летней историей. Высокая надёжность, автономность при отсутствии интернета, FIFO-учёт для строгой бухгалтерии. Предпочтителен для сложных форматов и холдингов.

> Успех внедрения на 70% зависит от компетенции интегратора — правильный выбор партнёра зачастую важнее выбора между двумя системами.

| Параметр | iiko | r_keeper |
|----------|------|----------|
| Архитектура | All-in-One, единая облачная БД | Модульная: касса и склад — разные программы |
| Тип развёртывания | Облако (iikoCloud) — основной фокус SaaS | Гибрид: локальный сервер + облако |
| Зависимость от интернета | Средняя/высокая (управление и отчёты требуют связи) | Низкая: кассовый сервер работает автономно |
| Финансовая модель | **OPEX** — только подписка | **CAPEX** (бессрочная лицензия) **или OPEX** (подписка) |

## Метод учёта себестоимости

**iiko** использует **средневзвешенную скользящую** себестоимость — списание в момент продажи. Удобен для управленца, которому важна прибыль здесь и сейчас.

**r_keeper + StoreHouse 5** работает по **FIFO** (партионный учёт) — «аптечная» точность при списании алкоголя (ЕГАИС) и дорогих ингредиентов. Незаменим для строгого бухгалтерского учёта.

## Когда выбрать iiko

- Ценят единую экосистему «из коробки» и скорость внедрения
- Важны масштабирование сети и встроенная онлайн-доставка
- Предпочитают предсказуемую OPEX-модель (подписку)
- Высокая текучка персонала — нужен быстрый онбординг

## Когда выбрать r_keeper

- Критически важны надёжность и автономность (нестабильный интернет)
- Уникальные бизнес-процессы, требующие глубокой кастомизации
- Необходим строгий партионный (FIFO) бухгалтерский учёт
- Готовы к капиталовложению (CAPEX) вместо ежемесячных платежей
- Фастфуд, ночной клуб, стадион, аэропорт — высоконагруженный формат

## Типичные ошибки при выборе

1. **Выбор только по цене лицензии** — экономия на интеграции обернётся потерями из-за ошибок в учёте
2. **Игнорирование аудита процессов** — нельзя автоматизировать хаос
3. **Пренебрежение требованиями ЕГАИС и маркировки** — убедитесь, что система и интегратор гарантируют соответствие
4. **Экономия на обучении персонала** — прямой путь к ошибкам в чеках
5. **Перенос старой схемы учёта «один в один»** — новая система — шанс оптимизировать процессы
