## About

**Poster POS** is a cloud automation system for food service. Runs on tablets and laptops. Positioned as the "first AI POS" — cash register, inventory, finances, analytics, and CRM in one interface. Free 15-day trial.

## Core modules

### Cash register (POS)
- Runs on any device (iPad, Android tablet, laptop)
- All order types: dine-in, takeaway, delivery
- Offline mode when internet drops

### Admin panel
- Analytics with ready-made reports
- Menu management + ABC analysis
- Real-time inventory tracking
- Financial reports and P&L
- Loyalty program and marketing tools
