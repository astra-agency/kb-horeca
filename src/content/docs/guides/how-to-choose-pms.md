## Шаг 1 — Определите тип объекта

| Тип объекта | Рекомендации |
|-------------|-------------|
| Хостел / мини-отель до 20 номеров | Bnovo или MaxiBooking |
| Апарт-отель / глэмпинг | Bnovo (сильный в краткосрочной аренде) |
| Городской отель 3* (20–60 номеров) | TravelLine LITE/STANDARD |
| Городской отель 4–5* (60+ номеров) | TravelLine PREMIUM или Logus HMS |
| Санаторий / курорт | Logus HMS или Saby Hotel |
| Сеть отелей | TravelLine или Logus HMS с централизованным управлением |
| Экосистема 1С/СБИС | Kontур.Отель или Saby Hotel |

## Шаг 2 — Обязательные функции: проверьте

- [ ] Шахматка — визуализация номеров по датам
- [ ] Создание и редактирование бронирований
- [ ] Check-in / check-out с расчётом стоимости
- [ ] Регистрация в МВД (Скала-Гостиница или аналог)
- [ ] Онлайн-касса по 54-ФЗ
- [ ] Channel Manager (встроенный или интеграция)
- [ ] Модуль прямого бронирования для сайта
- [ ] Мобильное приложение для управляющего

## Шаг 3 — Вопросы поставщику

1. **Включён ли Channel Manager в тариф?** — У Bnovo и MaxiBooking включён, у TravelLine — отдельная подписка
2. **Как настраивается регистрация в МВД?** — Автоматически через Скала-Гостиница или вручную?
3. **Сколько OTA-каналов поддерживает Channel Manager?** — Минимум: Ostrovok, Яндекс Путешествия, Суточно.ру, Booking.com
4. **Есть ли динамическое ценообразование?** — Автоматическое поднятие цен при высоком спросе
5. **Как интегрируется с бухгалтерией (1С)?**
6. **Что происходит при отключении интернета?** — Касса и шахматка должны работать локально
7. **Как осуществляется перенос данных при переходе?** — История бронирований, гостевая база

## Шаг 4 — Стоимость владения (TCO)

| Статья | TravelLine | Bnovo | MaxiBooking |
|--------|-----------|-------|------------|
| PMS (до 30 номеров) | 1 600 ₽/мес (LITE) | от 1 600 ₽/мес | от 1 500 ₽/мес |
| Channel Manager | +3 000 ₽/мес | Включён | Включён |
| Booking Engine | Отдельно | Включён | Включён |
| Внедрение | 0 (самостоятельно) | 0 (самостоятельно) | 0 |
| Обучение | Самостоятельно / вебинары | Самостоятельно / вебинары | Самостоятельно |

**Итого для мини-отеля:**
- TravelLine: ~4 600 ₽/мес (PMS + CM)
- Bnovo: ~1 600 ₽/мес (всё включено)
- MaxiBooking: ~1 500 ₽/мес (всё включено)

## Шаг 5 — Протестируйте

- **TravelLine** — демо по заявке на сайте
- **Bnovo** — бесплатный пробный период
- **MaxiBooking** — бесплатный тестовый доступ

**Что проверить:**
- Создание брони вручную за 2 минуты
- Синхронизация с Ostrovok (создайте тестовое объявление)
- Отчёт по загрузке за месяц
- Отправка формы в МВД (тестовая)

## Красные флаги

- Channel Manager не синхронизирует в реальном времени — риск овербукинга
- Нет интеграции со Скала-Гостиница — ручная работа с МВД нарушит сроки
- Нет мобильного приложения — неудобно для управляющего вне офиса
- Поддержка только email — при сбое во время высокого сезона критично
