## Context

PMS and CRM operate in silos: checkout data never reaches marketing, loyalty points don't sync with stay history, and personalization is impossible.

## Objective

Create a bidirectional integration between PMS (hotel) or POS (restaurant) and CRM so that every transaction triggers the right follow-up automatically.

## Results

- Guest profile enriched automatically after each stay or visit
- Repeat booking triggers sent within 24 hours of checkout
- Revenue from repeat guests increased by 18%
