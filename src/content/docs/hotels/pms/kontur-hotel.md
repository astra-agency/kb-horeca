## About

**Kontur.Hotel** is a cloud PMS from SKB Kontur — Russia's largest developer of accounting and tax software. Focused on small properties and non-standard accommodation formats.

## Key modules

### PMS — room management
- Visual booking calendar (room chart) in real time
- Check-in/check-out and room status management
- Hourly bookings (added in 2024)
- Automated document closing and reporting

### Channel Manager
- Connects to **35+ OTAs**: Booking.com, Ostrovok, Yandex Travel, Sutochno.ru, OneTwoTrip, and more
- Integration with **Otello** marketplace (added October 2024)
- Real-time synchronization, overbooking protection

### Online booking module
- Widget for website and social media
- Direct bookings without OTA commission

### Government reporting
- Automatic police/FMS guest data submission
- Foreign guest registration support

## 2024–2025 features

- **Hourly bookings** — for saunas, co-working spaces, aparthotels
- **Biometric check-in** — pilot with FGIS Biometrics (in development)
- Otello marketplace integration

## Kontur ecosystem integrations

- Kontur.Accounting — bookkeeping
- Kontur.OFD — fiscal data operator (online cash register)
- Kontur.EDO — electronic document flow
- API for third-party CRM and ERP systems

## Best for

| Format | Suitable |
|---|---|
| Small hotel, hostel (up to 30 rooms) | Yes — core audience |
| Aparthotel, guest house | Yes |
| Hotel up to 150 rooms | Yes |
| Resort, sanatorium | Yes |
| Hourly rental properties | Yes |
| Large chain 200+ rooms | No (use TravelLine/Logus) |

## Advantages

- Native integration with Kontur ecosystem (accounting, fiscal, EDO) — one vendor for everything
- Quick setup, no IT specialist required
- Russian compliance built-in out of the box
