## О продукте

**Контур.Отель** — облачная PMS от СКБ Контур (крупнейший разработчик бухгалтерского и налогового ПО в РФ). Специализируется на малых объектах и объектах с нестандартными форматами размещения.

## Ключевые модули

### PMS (управление номерным фондом)
- Визуальный календарь бронирований (шахматка) в реальном времени
- Управление заездами/выездами, статусами номеров
- Поддержка почасового бронирования (добавлено в 2024)
- Автоматическое закрытие документов и отчётности

### Channel Manager
- Подключение к **35+ OTA**: Booking.com, Ostrovok, Яндекс.Путешествия, Суточно.ру, OneTwoTrip и др.
- Интеграция с маркетплейсом **Отелло** (подключено в октябре 2024)
- Синхронизация в реальном времени, защита от овербукинга

### Модуль онлайн-бронирования
- Виджет для сайта и социальных сетей
- Прямые брони без комиссии OTA

### Государственная отчётность
- Передача данных в ФМС/МВД (автоматически)
- Поддержка требований для регистрации иностранных граждан

## Особенности 2024–2025

- **Почасовое бронирование** — для сауны, коворкингов, апарт-отелей
- **Биометрический check-in** — пилот с ФГИС «Биометрия» (в разработке)
- Интеграция с маркетплейсом «Отелло»

## Интеграции экосистемы Контур

- Контур.Бухгалтерия — бухгалтерский учёт
- Контур.ОФД — онлайн-касса и фискализация
- Контур.ЭДО — электронный документооборот
- API для подключения сторонних CRM и ERP

## Для каких объектов

| Формат | Подходит |
|---|---|
| Мини-отель, хостел (до 30 номеров) | Да — основная аудитория |
| Апарт-отель, гостевой дом | Да |
| Отель до 150 номеров | Да |
| Курорт, санаторий | Да |
| Объекты с почасовой арендой | Да |
| Крупная сеть 200+ номеров | Нет (лучше TravelLine/Logus) |

## Преимущества

- Нативная интеграция с экосистемой Контур (бухгалтерия, ОФД, ЭДО) — один поставщик для всего
- Простой старт, не требует IT-специалиста
- Соответствие российскому законодательству «из коробки»
