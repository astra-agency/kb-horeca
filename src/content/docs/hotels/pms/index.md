## Что такое PMS

**Property Management System (PMS)** — ядро ИТ-инфраструктуры отеля. Управляет:
- Номерным фондом и статусами номеров
- Заездами и выездами (check-in / check-out)
- Тарифами и ценообразованием
- Взаиморасчётами с гостями
- Отчётностью

## PMS-системы на российском рынке

| Система | Тип | Особенности |
|---|---|---|
| [TravelLine](./travelline.md) | Облако | Лидер рынка, полный стек (PMS + Channel Manager + модуль бронирования) |
| [Bnovo](./bnovo.md) | Облако | Хорошее соотношение цена/качество, простой интерфейс |
| [Контур.Отель](./kontur-hotel.md) | Облако | От экосистемы Контур, интеграция с ОФД и бухгалтерией |
| [Saby Hotel](./saby-hotel.md) | Облако | Модуль платформы Saby (ex-СБИС) |
| [Logus HMS](./logus-hms.md) | Облако/On-premise | Для крупных объектов, богатая функциональность |
| Автопортье | Облако | Небольшие отели и апартаменты |
| MaxiBooking | Облако | Мини-отели, хостелы |
| HotelCloud | Облако | Простота, быстрый старт |

## Что выбрать

- **Малый отель (до 30 номеров):** Bnovo, MaxiBooking, Автопортье
- **Средний отель (30–150 номеров):** TravelLine, Bnovo, Контур.Отель
- **Крупный объект / сеть:** TravelLine, Logus HMS, Saby Hotel
