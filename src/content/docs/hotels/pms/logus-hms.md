## О продукте

**Logus HMS** — PMS-система от компании Libra Hospitality (российская разработка, 2014). Клиент-серверная архитектура: устанавливается на сервер отеля. Работает автономно без интернета. Ориентирована на крупные объекты (100+ номеров) и гостиничные сети.

## Архитектура и развёртывание

| Параметр | Значение |
|---|---|
| Тип | On-premise (клиент-сервер) |
| Интернет | Не обязателен для работы |
| Скорость | Высокая (локальный сервер) |
| Обновления | По договору с Libra Hospitality |

## Основные модули

### Управление номерным фондом
- Номера и койко-места — обе единицы продаж
- Расчёт стоимости: по ночам, дням или часам
- Блокировки номеров, лимиты овербукинга
- Разделённый счёт для гостей, делящих номер с разными тарифами

### Тарифная политика
- Гибкие базовые тарифы с автоматической коррекцией связанных цен (корпоративные/агентские)
- Сезонные тарифы, тарифы по длительности проживания
- Управление пакетами услуг

### Корпоративные клиенты и агентства
- Собственный кабинет для корпоративных партнёров и турагентств
- Самостоятельное управление блоком номеров, квотами, тарифами
- Создание/отмена броней с автоматическим отражением в PMS

### Групповые бронирования
- Управление группами, мероприятиями, конференц-залами
- Отдельный модуль банкетов и событий

### Ресторанные интеграции
- Прямая интеграция с iiko и r_keeper
- Room charge (перевод счёта с ресторана на номер)

### Многообъектная отчётность
- Сводные отчёты для сетей
- Детальная аналитика по каждому объекту

## Интеграции

- Ресторанные системы: iiko, r_keeper
- Платёжные терминалы и банковские системы авторизации карт
- Электронные замки
- Фискальные регистраторы
- Платформы онлайн-бронирования
- Доступ корпоративных партнёров через кабинет

## Стоимость

Формируется индивидуально. Зависит от:
- Количества номеров
- Набора модулей (каждый интерфейс — отдельно)
- Формата развёртывания

Контакт: [librahospitality.com](https://www.librahospitality.com/logus_hms/)

## Для каких объектов

| Тип | Подходит |
|---|---|
| Крупный городской отель (100+ номеров) | Да — целевая аудитория |
| Курорт, санаторий | Да |
| Гостиничная сеть | Да — мультиобъектная отчётность |
| Конгресс-отель с мероприятиями | Да |
| Мини-отель, хостел | Нет (избыточно) |

## Преимущества

- Работает без интернета — критично для объектов с нестабильным соединением
- Глубокое управление корпоративными контрактами
- Интеграция с ресторанными системами (iiko, r_keeper) нативно
- Российская разработка с 2014, поддержка российского законодательства
