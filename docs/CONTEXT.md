# Контекст проекта

## Цель

Создать публичную базу знаний по ИТ-сервисам для HoReCa (отели, рестораны, кафе) на российском рынке. Целевая аудитория — владельцы и управляющие объектов HoReCa, которые выбирают или внедряют автоматизацию.

Деплой: GitHub Pages, домен `https://astra-agency.github.io/kb-horeca/`.

---

## Что сделано

### Инфраструктура
- Astro 6.4.4 + Starlight 0.39.3 — настроен и работает
- `astro.config.mjs` — `site`, `base`, локаль `ru`, полный sidebar
- `.github/workflows/deploy.yml` — GitHub Actions для деплоя в Pages
- `.gitignore` — добавлены `node_modules`, `dist`, `.agents`

### Раздел «Отели» — нетехнический контент (28 страниц)
- Подразделы: Управление доходом, Персонал, Гостевой опыт, Операции
- Каждый подраздел: обзор + 3–5 тематических статей

### Раздел «Рестораны» — нетехнический контент (16 страниц)
- Подразделы: Меню и экономика, Персонал, Операции, Гостевой опыт
- Каждый подраздел: обзор + 2–4 тематических статьи

### Раздел «Кейсы» (16 статей + индекс)
- `cases/index.md` — каталог кейсов по категориям
- 5 групп: CRM и продажи, Лояльность, Бронирование, Автоматизация отделов, Мобильные решения
- Все кейсы: Контекст → Задача → Что сделано → Результат → Связанные материалы

### Раздел «Сервисы» — IT контент
- Отели IT: PMS (7 систем + сравнение), Channel Manager, бронирование, репутация, CRM
- Рестораны IT: POS (iiko, r_keeper, Poster + сравнение), доставка, лояльность, резервация

### Перелинковка кейсов ↔ KB-статьи
- 11 статей получили секцию «Кейсы по теме» с релевантными кейсами

## Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Данные о ценах устаревают | Высокая | Ставить дату последней проверки на страницах |
| Сайты вендоров недоступны для скрейпинга | Высокая | Использовать поиск + знания, ставить ссылки на источники |
| Страницы EN-заглушек (`guides/*`) в sidebar — пустые | Средняя | Либо заполнить, либо убрать из sidebar в `astro.config.mjs` |
| GitHub Pages не включён вручную | Высокая | Нужно зайти в Settings → Pages и активировать |
| Ветка `feature/restructure-horeca-kb` не смержена в `main` | Высокая | Merge перед деплоем |
